\# Schema Breakage

\## Definition

Structural graph violates declared schema definitions.

\## Structural Signature

\- Declared schema

\- Structural instance contradicting schema

\- Type or shape violation

\## Deterministic Test

Given declared schema, structural graph must conform to schema rules.

If violation occurs, Schema Breakage exists.

\## Structural Limits

Does not evaluate schema correctness.

Evaluates schema compliance only.
