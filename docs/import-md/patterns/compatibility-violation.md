\# Compatibility Violation

\## Definition

Structural graph exceeds declared runtime or platform compatibility
constraints.

\## Structural Signature

\- Declared compatibility envelope

\- Structural property outside envelope

\- No declared exception

\## Deterministic Test

Given declared compatibility constraints, structural graph must remain
within bounds.

If constraints are exceeded, Compatibility Violation exists.

\## Structural Limits

Does not evaluate authority legitimacy.

Evaluates compatibility compliance only.
