\# Constraints Underspecified

\## Definition

Declared constraints are insufficient to eliminate structural degrees of
freedom.

\## Structural Signature

\- Structural graph with multiple admissible states

\- No constraint eliminating ambiguity

\## Deterministic Test

Given declared constraints, only one admissible structural state should
exist.

If multiple states remain valid, Constraints Underspecified exists.

\## Structural Limits

Does not evaluate correctness of constraints.

Evaluates completeness only.
