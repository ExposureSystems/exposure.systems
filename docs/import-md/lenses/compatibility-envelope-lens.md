\# Compatibility Envelope Lens

\## Definition

Determines whether structure fits within declared runtime or platform
constraints.

\## Structural Transform

Input:

\- Structural graph

\- Declared compatibility constraints

Operation:

\- Compare structural properties against compatibility rules

\- Identify incompatibilities

Output:

\- Compatibility classification

\- Violation regions (if present)

\## Input Requirements

\- Explicit compatibility definitions

\## Structural Signature of Failure

Failure exists when structural graphs violate declared compatibility
constraints.

\## Structural Limits

Evaluates compatibility only.

Does not evaluate authority legitimacy.
