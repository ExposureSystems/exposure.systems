# Asymmetric Structure

## Definition

Structurally comparable regions exhibit unequal or inconsistent rule
application.

## Structural Signature

- Comparable structural domains

- Unequal constraints or authority application

- No declared differentiation rule

## Deterministic Test

Given structurally equivalent regions, rules must apply symmetrically
unless explicitly differentiated.

If not, Asymmetric Structure exists.

## Structural Limits

Does not evaluate correctness of differentiation.

Evaluates structural symmetry only.
