# Invariant Breakage

## Definition

A declared invariant is violated within the observed structural graph.

## Structural Signature

- Declared invariant rule

- Structural state contradicting rule

## Deterministic Test

Given declared invariants, structural state must satisfy all invariant
conditions.

If violated, Invariant Breakage exists.

## Structural Limits

Does not evaluate validity of the invariant itself.

Evaluates compliance only.
