# Orphaned Structure

## Definition

Structural elements exist without inbound or outbound linkage to the
governing graph.

## Structural Signature

- Isolated node or region

- No governing reference

- No integration pathway

## Deterministic Test

Given a structural graph, all nodes must connect to the declared
governing structure.

If a node remains unconnected, Orphaned Structure exists.

## Structural Limits

Does not evaluate structural validity.

Evaluates graph connectivity only.
