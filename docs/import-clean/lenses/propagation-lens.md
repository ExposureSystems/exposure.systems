# Propagation Lens

## Definition

Traces how structural declarations propagate across boundaries or
stages.

## Structural Transform

Input:

- Structural graph

- Declared propagation sources

Operation:

- Trace propagation paths

- Identify scope expansion

Output:

- Propagation map

- Overextended regions (if present)

## Input Requirements

- Defined propagation rules

## Structural Signature of Failure

Failure exists when structural declarations extend beyond declared
scope.

## Structural Limits

Evaluates propagation behavior only.

Does not evaluate authority legitimacy.
