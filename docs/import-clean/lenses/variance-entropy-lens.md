# Variance / Entropy Lens

## Definition

Measures structural variability across multiple evaluations.

## Structural Transform

Input:

- Structural graphs from repeated evaluations

Operation:

- Compare structural differences across runs

- Quantify divergence magnitude

Output:

- Variance classification

- Divergence metrics (if present)

## Input Requirements

- Comparable structural graphs

## Structural Signature of Failure

Failure exists when structural divergence exceeds expected bounds across
evaluations.

## Structural Limits

Measures variability only.

Does not evaluate causation.
